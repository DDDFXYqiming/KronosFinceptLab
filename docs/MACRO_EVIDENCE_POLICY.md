# 宏观洞察证据与监控信号规则

## 概率估计

宏观页面的“概率估计”是模型基于本轮信号生成的情景权重，不是经过历史回测校准的统计概率。

后端会统一处理百分比/小数格式、裁剪非法值，并将有效情景归一化到 100%。报告同时返回 `probability_method` 和 `probability_note`，用于区分：

- `llm_scenario_weight`：LLM 基于本轮证据生成的情景权重。
- `provider_confidence_fallback`：LLM 未返回有效情景时，基于 provider 信号置信度生成的降级权重。

页面必须明确展示“模型情景权重，非统计校准概率”，不得将其描述为胜率或确定性预测。

## 待监控信号

监控项的当前值必须优先来自结构化 provider，并保留 provider、来源 URL、观测时间、抓取时间、数据状态和时效状态。

- 价格、成交量、利率、收益率、指数、持仓、销量、产量和库存等数值型信号：没有结构化来源时显示“未获取”，不得从 LLM 或搜索摘要补数。
- 公告、政策、减产、订单、指引和其他事件型信号：结构化来源缺失时可以调用 AnySearch。
- AnySearch 结果必须同时具备 URL 和发布日期；缺少日期的结果不能标记为当前信息。
- AnySearch 只能作为“新闻背景/定性证据”，不得作为实时价格或数值阈值来源。
- 时效窗口：快变量 72 小时，月度/行业数据 45 天，公告/政策 30 天；超过窗口显示为过期或不可用。

AnySearch fallback 最多并行处理 4 个监控项，单项和总请求均有超时限制，不重试。fallback 失败后保留监控项，但当前值必须是“未获取”。

## 前端展示

监控表必须区分“结构化数据”“AnySearch 新闻”和“未获取”，显示观测日期及来源链接。新闻日期和抓取时间不能混用，日期未知时不能显示为当前时间。
